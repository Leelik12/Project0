# Project0: TechnoDeath

VR-шутер с roguelike-прогрессией в сеттинге киберпанка. Игрок поднимается по этажам «Мегабашни», зачищает их от врагов, между этажами покупает оружие и киберимпланты, и в финале сражается с боссом — боевым вертолётом.

Курсовая работа. Движок — **Unity 6000.2.9f1**, VR через **OpenXR + XR Interaction Toolkit 3.2**.

> Концепция и обоснование дизайна — в [Отчет.pdf](Отчет.pdf).

## Геймплей

**Этажи.** 4 боевых этажа + босс. Условие прохождения этажа — уничтожить всех врагов; после этого открываются двери лифта. На некоторых этажах спрятан опциональный предмет — он даёт дополнительную (пятую) карточку в магазине.

**Враги.** Три типа: ближний бой, пистолет, винтовка. ИИ на конечном автомате (Idle → Patrol → Agro → Attack / Search / Death) с конусом зрения, памятью последней позиции игрока и «заражением» агрессией — если один враг вас заметил, соседи в радиусе тоже переходят в бой. Попадание в голову — двойной урон, в ноги — половинный, но замедляет врага.

**Оружие** (код в `GameState.CurrentGun`):

| Код | Оружие | Патроны |
|---|---|---|
| 0 | АКМ | магазин |
| 1 | Лазерный пистолет | бесконечно |
| 2 | Лазерная винтовка | бесконечно |
| 3 | Пистолет | магазин |
| 4 | Граната (дополнительно к основному) | — |
| 5 | Винтовка P40 | магазин |
| 6 | Дробовик | магазин |
| 7 | Полицейская дубинка | — |
| 8 | Бейсбольная бита | — |

Магазины — физические объекты: полный магазин вставляется касанием оружия, пустой выбрасывается автоматически. Запасные магазины хранятся на поясе. Стреляет только та рука, в которой лежит оружие (грип + триггер).

**Магазин апгрейдов** между этажами показывает 4 случайные карточки (оружие / имплант / улучшение оружия / смешанная) + пятую, если найден предмет. Покупка одна за визит.

**Киберимпланты:**

| Имплант | Эффект |
|---|---|
| +HP | Больше максимального здоровья |
| Быстрые ноги | Постоянное ускорение |
| Сильные руки | Множитель урона в ближнем бою |
| Ускорение после урона | Кратковременный рывок при получении урона |
| Пропитал | По кнопке восстанавливает HP (1 раз за этаж) |
| Сандевистан | По кнопке замедляет время (1 раз за этаж) |
| Акимбо | Второй пистолет (только для кодов 1 и 3) |
| Катана | Клинок в левой руке |
| ЛЦУ | Лазерный прицел работает даже на сложном режиме |

**Сложность.** «Легко» — оружие с лазерным прицелом; «Сложно» — без него.

**Достижения** (экран в главном меню): 100 / 500 выстрелов, 100 / 500 попаданий, 1000 / 5000 урона, «Стать боргом» (сильные руки + ноги в одном забеге), «Таков киберпанк» (первая смерть).

## Игровой цикл

```
LobbyScene (меню, тир) ──► TheFirstLevel ──► Lobby (магазин) ──► Basement ──► Lobby ──► HighFloor
        ▲                                                                                  │
        │                                                                                  ▼
   победа / смерть ◄──────────── BossFight ◄──── Lobby ◄──── HappyRoomAndSmallBossfight ◄──┘
```

Индексы сцен в Build Settings: `0` LobbyScene, `1` Lobby (магазин), `2` TheFirstLevel, `3` Basement, `4` HighFloor, `5` HappyRoomAndSmallBossfight, `6` BossFight.

Лифт на этаже (`ElevatorController`) запоминает индекс текущей сцены в `GameState.CurrentLevel` и везёт в магазин; лифт магазина (`UpdateLiftController`) везёт на `CurrentLevel + 1`. Смерть или победа сбрасывают забег (`GameState.ResetRun()`) и возвращают в меню с экраном поражения / победы. Настройки и статистика достижений сохраняются в `PlayerPrefs`.

## Управление

| Действие | Ввод |
|---|---|
| Передвижение | левый стик |
| Поворот | правый стик |
| Взять предмет | грип |
| Выстрел | грип + триггер руки с оружием |
| Взвести гранату | грип + триггер, затем бросить |
| Пропитал / Сандевистан / Меню | кнопки контроллера (настраиваются в `PlayerHealth` на XR Origin) |

## Как запустить

1. Unity Hub → установить **6000.2.9f1** с модулем *Android Build Support* (для Quest) и/или *Windows*.
2. Открыть папку проекта; первый импорт занимает 10–20 минут.
3. Для PC VR: подключить шлем через Meta Quest Link / SteamVR, открыть `Assets/_Project/Scenes/LobbyScene.unity`, нажать Play.
4. Для сборки: `File → Build Profiles`, платформа Windows или Android, сцены уже прописаны.

## Архитектура кода

`Assets/_Project/Scripts` — ~3 000 строк, без внешних зависимостей кроме XRI.

| Папка | Что там |
|---|---|
| `Core/` | `GameState` — статическое состояние забега, настройки, сохранение в PlayerPrefs |
| `Player/` | `PlayerHealth` (HP, импланты, меню паузы, HUD), синхронизация коллайдера с головой, пояс, анимация рук, хват |
| `Weapons/` | `VRGun` (hitscan, магазины, отдача, лазер), `VRMagazine`, `VRGrenade`, `MeleeWeaponDamage`, `WeaponSpawnManager` |
| `Enemies/` | `EnemyStateManager` + `States/` (конечный автомат), `EnemyHealth`, `EnemyGun`, контроллер хвата оружия, засады |
| `Boss/` | `HelicopterController` (полёт, кружение, побег), `HelicopterGunSystem` |
| `Level/` | `LevelManager` (цели этажа), лифты на базе `SceneLoaderBase`, двери на базе `SlidingDoor`, подбор предмета |
| `Upgrades/` | `ButtonFunction` (обработчики карточек), `UpgradeCanvasSpawner` (случайные карточки), `CanvasManager` |
| `UI/` | главное меню, слайдеры громкости, сложность, достижения, `HudAmmoDisplay` |

Поток данных простой: сцены пишут и читают `GameState`; между сценами он живёт как static, при выходе из игры — в PlayerPrefs.

## Правила при доработке

- **Не переименовывать** классы `ButtonFunction`, `CanvasManager`, `DifficultyChanger`, `GrabParenter`, `PlayerHealth`, `SceneManagerMain` и их публичные методы — они привязаны к кнопкам и событиям в сценах по имени.
- Методы `EnemyStateManager.CheckConditions`, `Shoot`, `PlayFootstep` вызываются из Animation Events — тоже по имени.
- Имена сериализуемых полей менять только через `[FormerlySerializedAs]`, иначе ссылки в инспекторе обнулятся.
- Новые состояния врага — наследники `EnemyBaseState`; новые двери — наследники `SlidingDoor`; новые лифты — `SceneLoaderBase`.
- Скрипты — UTF-8 с BOM, CRLF (как настроено в Visual Studio).
- Ассеты из стора кладём в `Assets/ThirdParty`, своё — в `Assets/_Project`. Целиком демо-сцены паков в репозиторий не тащим.

## Что не реализовано

По сравнению с концептом из отчёта:

- HUD показывает только здоровье и патроны; брони и индикаторов имплантов нет.
- Экран загрузки с советами: есть только прогресс-бар (настроен в сцене Basement).
- Достижения только отображаются, предметов не открывают.
- Динамическая сложность — только статический переключатель.
- Случайная генерация этажей — этажи фиксированные.
