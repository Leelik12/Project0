# Project0

Курсовая работа — VR-шутер, разработанный на движке **Unity**.

> ⚠️ Проект находится в разработке и может дорабатываться.

## Описание

Project0 — это VR-игра в жанре шутера. Проект создан в рамках курсовой работы и представляет собой прототип VR-опыта с боевой механикой от первого лица.

## Технологии

- **Unity** (игровой движок)
- **C#** (язык скриптов)
- Виртуальная реальность (XR Interaction Toolkit)

## Структура репозитория

```
Project0/
├── Assets/            # Ресурсы проекта: сцены, скрипты, модели, материалы и т.д.
├── Packages/          # Зависимости и пакеты Unity
├── ProjectSettings/   # Настройки проекта Unity
├── .gitignore
├── .vsconfig
└── README.md
```

## Требования

- [Unity Hub](https://unity.com/download) и версия Unity, указанная в `ProjectSettings/ProjectVersion.txt`
- VR-гарнитура и соответствующее ПО (Meta Quest Link) для тестирования в виртуальной реальности
